# 📝 Todo App (React + TypeScript + Tailwind CSS)

A modern and scalable **Todo Application** built with **React, TypeScript, Context API, Tailwind CSS**, and **LocalStorage**.  
It is designed with a modular architecture using reusable components, custom hooks, and strongly typed TypeScript definitions.

---

## 🚀 Features

### ✅ Task Management
- ➕ Add new todos
- ❌ Delete todos
- ✏️ Edit / update todos
- 📌 Toggle todo status (custom states supported)

### 🔍 Advanced Filtering System
This project supports **multiple filtering options**, such as:
- Filter by category
- Filter by Difficulty
- Filter by priority 
- Filter by date
- Filter by title

### ⏰ Reminders
- Set reminders for individual todos
- Time-based reminder support (UI or alert-based)
- Helps in task scheduling and productivity tracking

### 💾 Persistent Storage
- Uses **LocalStorage**
- Automatically saves and restores state on reload

---

## 🧠 Tech Stack

- ⚛️ React
- 🟦 TypeScript
- 🎯 Context API (State Management)
- 🎨 Tailwind CSS
- 💾 LocalStorage

---

## 📁 Project Structure

- `src/`
  - `components/` — Reusable UI components
  - `state/` — Global state management (Context API)
  - `hooks/` — Custom React hooks
  - `utils/` — Helper functions & logic
  - `types.d.ts` — Global TypeScript type definitions
  - `App.tsx` — Main application entry point
